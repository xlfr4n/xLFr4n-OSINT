# 🤝 Contributing to xLFr4n-OSINT

🇪🇸 Las contribuciones deben mantener el proyecto claro, reproducible y verificable.  
🇬🇧 Contributions should keep the project clear, reproducible and verifiable.

## Workflow

1. Understand the existing architecture.
2. Keep source provenance explicit.
3. Add tests for new parsing or normalization behavior.
4. Document external services and rate limits.
5. Never commit secrets or private datasets.
6. Keep Spanish and English documentation aligned where practical.

## Verification

Before opening a pull request, run the project checks that apply to the changed area.

A contribution should not claim a provider, API or capability that has not been tested.

## Style

Use focused commits and keep unrelated changes separate.

> ⚡ Investigate → Build → Verify → Document
